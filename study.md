# BRIEFING


> 1. delta = Actual − Previous, excluding forecast entirely.
> 2. Higher interest rates relative to other countries → potentially more attractive returns on investments


| Event | Plain meaning | If delta > 0 | If delta < 0 |
|---|---|---|---|
| **CPI / core CPI** | How fast consumer prices are rising | Inflation rate increased → usually USD-supportive | Inflation rate decreased → usually USD-negative |
| **PCE inflation / core PCE** | Another measure of consumer inflation; PCE is the Fed’s target measure | Inflation rate increased → usually USD-supportive | Inflation rate decreased → usually USD-negative |
| **PPI** | How fast prices received by producers are rising | More producer-price pressure → potentially USD-supportive | Less producer-price pressure → potentially USD-negative |
| **NFP / payrolls** | Monthly jobs added or lost | More jobs added, or fewer lost → usually USD-supportive | Fewer jobs added, or more lost → usually USD-negative |
| **Jobless claims** | People applying for unemployment benefits | More claims → weaker labor signal → usually USD-negative | Fewer claims → stronger labor signal → usually USD-supportive |
| **GDP growth** | How fast inflation-adjusted economic output is growing | Faster growth, or a smaller contraction → usually USD-supportive | Slower growth, or a larger contraction → usually USD-negative |
| **Retail sales growth** | How fast spending at retailers is changing | Faster spending growth → usually USD-supportive | Slower spending growth → usually USD-negative |
| **ISM Manufacturing / Services** | Surveys showing whether business activity is improving or worsening | Higher headline index → usually USD-supportive | Lower headline index → usually USD-negative |
| **Fed interest-rate decision** | The Fed’s policy rate | **Hike** → usually USD-supportive | **Cut** → usually USD-negative |
| **Fed Chair speeches / testimony** | What the Chair says about inflation, jobs and policy | No meaningful numerical A−P rule | Read the message instead |


> For delta = 0: the number gives no new direction compared with the previous reading. It does not mean the underlying situation is neutral.
