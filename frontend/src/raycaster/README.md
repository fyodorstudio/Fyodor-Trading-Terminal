# Raycaster

R1 presents EUR/USD evidence at the cursor candle's end. Context, Context-detailed
and Selected combo remain selectable retired views with separate legacy models.
Scoring development is paused; use the
[main objective](../../../fyodor%20trading%20terminal%20main%20objective.md) for current scope.

| Folder | Responsibility |
| --- | --- |
| `ui/` | R1 reading, evidence tanks and retained view components |
| `core/` | Cached presentation and cursor lookup |
| `Raycaster.tsx`, `chart/` | View composition and chart interaction |
| `storage/` | Saved visibility/view preferences and compatibility exports |
| `ribbon/` | Candy timeline presentation |

[R1](../scoring-system/r1/README.md) owns arithmetic, snapshots, changes and timeline
workers. [USD context](../usd-context/README.md), [relative context](../pair-context/README.md)
and [Roofs](../usd-context/sequences/README.md) own retained legacy integrations.
No view silently migrates those models to R1.

Hover looks up prepared history. Hidden R1 views stop workers/polling. Model settings
are shared with Inspector/Scatter; Inspector visibility filters are independent.
Preserve publication clocks, simultaneous updates, correction/expiry distinctions
and stable data identities. Visual audits belong to the user.
