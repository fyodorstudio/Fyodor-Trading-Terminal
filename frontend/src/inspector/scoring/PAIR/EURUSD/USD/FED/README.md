# USD Fed rate-action v1 / text coverage

This is partial policy interpretation, not a statement or speech sentiment model.
`assessment/` checks one verified rate decision and compares the stored actual
with Revised Previous when supplied, otherwise Previous. Hike/cut -> Short/Long
EURUSD under the declared USD action rule, with Weak action evidence. Hold ->
Rate hold, no action direction. Speech/commentary without content -> Uncomputed.

`ui/` displays that factual/action interpretation alongside the common
publication-time macro context. Context does not claim what the Fed said.
Statements, projections, answers and speech content are absent from the feed.
No action/tone vote enters Raycaster until an explicit guidance policy has a
supported, timestamped content source. Companion rows keep their own times.
