# Retired analyst learning engine

Routine news refreshes no longer freeze forecasts, capture outcomes, score
excursions or run an evaluation loop. The original implementation and full
records remain in [the preservation archive](RESEARCH-ARCHIVE.md).

Latest active process lessons were extracted with source IDs to
`docs/research-lessons.json`. Retrieve only a relevant currency with
`pnpm analyst news lessons --scope CAD`. These are reviewed process observations,
not model-weight training, calibrated forecasts or proof of a trading edge.
The [EURCAD failure audit](research-audits/2026-11-03-eurcad.md) retains the original
wrong calls, opposing evidence and measured limitations for optional review.
